# Agent Workbench UI 스타일 가이드

화면을 바꿀 때 지키는 규칙이다. 값은 `styles.css`의 `:root`(정본)에 있고, 이 문서는 **역할과 규칙**을 적는다.
디자인 체계는 Orca(MIT, `THIRD_PARTY_NOTICES.txt`)의 스타일 가이드를 이 앱(바닐라 JS + CSS 한 파일)에 맞게 옮긴 것이다. 분석: `docs/design/orca-analysis.md`.

정체성은 **단색이고 조용하다**. 회색이 화면 틀을 맡고, 색은 상태에만 쓴다. 이 앱은 터미널·채팅·diff를 담는 틀이므로 틀은 물러나고 내용이 앞에 선다.

- 색보다 `muted`·`accent`·`border`를 먼저 쓴다.
- hex보다 CSS 변수를 먼저 쓴다.
- 새 CSS를 쓰기 전에 4장의 기본 부품(버튼 변형, 입력, 메뉴 행, 칩)을 먼저 맞춰 본다.

## CSS 파일 구성

`styles.css`는 이 순서를 지킨다. 새 규칙은 해당 장에 넣고, 파일 끝에 덧붙이지 않는다.

## 색

면(surface)과 그 위 글자(foreground)를 짝으로 쓴다.

| 토큰 | 쓰는 곳 |
|---|---|
| `--background` | 앱 바탕, 터미널(`--terminal`) |
| `--card` | 제목줄·탭 줄·상태줄, 바탕에서 한 단 올라온 패널 |
| `--sidebar` | 왼쪽·오른쪽 사이드바, 앱 레일 |
| `--canvas` | 채팅·편집 영역. 사이드바(`--sidebar`)보다 밝게 두어 영역이 선 없이도 나뉜다(Orca 측정값 기준 약 13단계 차) |
| `--popover` | 메뉴·팝오버 |
| `--editor-surface` | 노트·diff 본문. 앱 틀에는 쓰지 않는다 |
| `--primary` | 흐름마다 **하나뿐인** 확정 버튼. 장식·hover에 쓰지 않는다 |
| `--secondary` | 확정 버튼 옆 낮은 단계 버튼 |
| `--muted` / `--muted-foreground` | 설명·캡션·placeholder·비활성. 본문 글자에는 쓰지 않는다 |
| `--accent` | ghost 버튼·목록 줄의 hover와 현재 줄 배경(회색) |
| `--destructive` | 삭제·되돌릴 수 없는 동작과 오류. **취소에는 쓰지 않는다** |
| `--border` / `--border-strong` | 모든 구분선 / 카드·메뉴 테두리 |
| `--input` | 입력칸·outline 버튼 테두리 |
| `--ring` | 키보드 포커스 링. 지속 장식으로 쓰지 않는다 |

상태 색은 상태에만 쓴다.

| 토큰 | 상태 |
|---|---|
| `--agent-working` | 작업 중(회전 표시) |
| `--agent-question` / `-text` | 에이전트가 사용자를 기다림(승인·로그인·입력) |
| `--status-done` | 완료 점 |
| `--success`, `--warning`, `--destructive` | 성공 · 주의 · 실패 |
| `--diff-added`, `--diff-removed` | diff와 변경 수치에만 |
| `--unread` | 읽지 않음, 터미널 활성 칸 표시 |
| `--claude` | Claude 표식에만 |

- 컴포넌트 규칙에 hex를 쓰지 않는다. 새 색은 `:root`에 토큰으로 넣고 쓴다.
- 옅은 색은 `color-mix(in srgb, var(--토큰) N%, transparent)`로 만든다.
- 목록 줄: 평소 투명 → hover `accent` 40~50% → 현재 줄 `accent`(또는 카드는 옅은 면 + `--border-strong`). "선택됨" 색을 따로 만들지 않는다.
- `renderer.js`가 xterm 색으로 읽는 `--terminal`, `--text`, `--terminal-selection`은 이름을 바꾸지 않고 순수 색값으로 둔다.

## 글자

- 본문은 `Geist`, 한글은 `Pretendard Variable`(둘 다 `assets/fonts`에 포함). 고정폭은 `--mono`(경로, 코드, 명령, 브랜치).
- 자간은 `:root`에서 한 번(`0.01em`)만 준다.
- 크기 단계만 쓴다: `--text-base` 14px(대화상자·설정) · `--text-sm` 13px(본문, 사이드바·메뉴 줄, 채팅) · `--text-xs` 12px(보조 글자·경로·작은 버튼) · `--text-2xs` 11px(캡션·분류 이름) · `--text-3xs` 10px(배지·단축키).
- 분류 이름(구역 제목)은 11px, semibold, 대문자, 자간 0.05em.
- 채팅은 13px 본문에 줄 높이 20px, 코드는 12px.

## 모양과 높이

- 모서리: `--radius-sm` 6px(메뉴 줄·작은 버튼) · `--radius-md` 8px(버튼·입력) · `--radius-lg` 10px(메뉴·배너) · `--radius-xl` 14px(카드·대화상자·입력창) · `--radius-full`(칩).
- 높이는 세 단계뿐이다. (1) `border` 한 줄 — 거의 전부 (2) `--shadow-xs` + 테두리 — outline 버튼 (3) `--shadow-floating` — 메뉴·팝오버. 토스트·대화상자·팔레트·플로팅 터미널은 `--shadow-notice`.

## 기본 부품

**버튼** (`button`)

| 변형 | 용도 |
|---|---|
| (기본) outline | 도구줄·단독 동작 |
| `.primary` | 흐름의 유일한 확정 동작 |
| `.secondary` | 확정 버튼 옆 |
| `.ghost` | 취소·닫기·버리기, 줄 안 동작 |
| `.icon-button` | 아이콘만 있는 버튼(ghost 모양) |
| `.danger` | 되돌릴 수 없는 삭제. 취소에는 쓰지 않는다 |

크기는 그 줄 높이에 맞춘다: 기본 32px, 도구줄 26~28px, 촘촘한 줄 22~24px. 아이콘 버튼은 정사각형.

**아이콘**: `icons.js`(Lucide)만 쓴다. `setPanelIcon(element, 이름)` 또는 마크업의 `data-icon="이름"`. 기본 16px, 촘촘한 줄 12~14px, 색은 글자색을 따른다. 글자 기호(`＋ × ↻ ›_`)를 아이콘 대신 쓰지 않는다. 새 아이콘은 scratch 스크립트처럼 lucide 패키지에서 노드를 가져와 `icons.js`에 더한다.

**상태 표시**(`stateGlyph`): 12px 칸 안에 작업 중은 회전 표시, 기다림은 주황 물음표, 완료·실패는 6px 점. 줄이 흔들리지 않게 칸 크기를 바꾸지 않는다.

**에이전트 표식**(`agentMark`): 실제 브랜드 마크를 쓴다. Claude는 주황 별(`claude-logo`, `--claude`), Codex는 OpenAI 마크(`openai-logo`, 글자색). 탭·사이드바 카드·채팅 답변 머리·입력창 아래 정보 줄·상태줄에 같은 표식을 쓴다. 채우기 도형이라 `-logo` 아이콘은 stroke 대신 fill로 그린다.

**떠 있는 창**: 새 Markdown 노트는 플로팅 노트 창에서, 셸은 플로팅 터미널에서 열고, 두 창 모두 최대화하면 메인 탭으로 옮긴다(Orca와 같음). 노트는 "서식"(TipTap WYSIWYG)과 "원본"(Markdown 글) 두 모드. 두 창 모두 `--shadow-notice`, `--radius-xl`.

**입력**: 같은 면·모서리·테두리, 포커스는 `--ring` 테두리 + 3px 링. 오류는 `aria-invalid`.

**스위치**: `input[type=checkbox][role=switch]`. **선택지 2~4개**는 `.segmented`.

**메뉴**: 팝오버 면, 4px 안쪽 여백, 줄은 32px·6px 모서리, hover는 `accent`. 구분은 `hr`이나 `.tab-menu-group` 윗선.

**토스트**: 일시적 결과에만. 읽고 다시 시도해야 하는 오류는 그 자리(배너·`.dialog-error`)에 남긴다.

## UX 규칙

1. **문구는 과장하지 않는다.** 실제 결과가 있을 때만 "완료", "저장함", "삭제함"을 쓴다. 진행 중에는 과정을 말한다("확인 중…").
2. **진행 표시는 걸리는 시간에 맞춘다.** 0~100ms 없음 · 100ms~1초 비활성만 · 1~3초 비활성 + 회전 표시 · 3초 넘게나 여러 단계면 단계 이름.
3. **글자가 바뀌는 버튼은 너비를 미리 잡는다.** 동작 중에 크기가 바뀌면 고장 난 것처럼 보인다.
4. **물러나는 길은 조용하게.** 취소·닫기는 `.ghost`, 색·단축키 칩 없음. Esc는 동작한다.
5. **옆 부품과 맞춘다.** 같은 흐름의 이웃 부품은 아이콘·단축키·제출 방식이 같다.
6. **접는 화살표는 제목 앞에.** 펼침 아래, 접힘 오른쪽.
7. 확정 동작은 한눈에 보이고, 흔한 일은 1~2번 조작. 기본 포커스는 가장 가능성 높은 칸, Enter로 제출.
8. **데이터가 없으면 얻는 방법을 보여 준다**(첫 실행 안내처럼).
9. 툴팁(`title`)은 이름이 안 보이는 아이콘 버튼에만. 중요한 메시지를 툴팁에 넣지 않는다.
10. 움직임 줄이기 설정에서 회전 표시는 멈춘 채 보인다.

## 이 문서에 없는 경우

1. 같은 장에서 가장 가까운 부품을 찾아 따른다.
2. 토큰 문제면 `:root`에 있는 값을 쓰거나 새 토큰을 넣는다.
3. 그래도 정하지 못하면 묻는다.
